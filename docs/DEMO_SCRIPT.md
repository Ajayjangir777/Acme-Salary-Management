# Demo script (3–5 minutes)

1. Explain the problem and MVP scope.
2. Show dashboard and salary summaries grouped by currency.
3. Search and filter employees.
4. Edit a fictional employee and verify persistence.
5. Create an employee and demonstrate validation.
6. Show Swagger UI, tests, seed configuration and architecture notes.
7. Explain trade-offs and production gaps.
Record only after verifying the deployed URL. Never show secrets or real salary data.
